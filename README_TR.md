## Nasıl Kullanılır? 🚀

İlgilendiğin proje klasörünü açıp o projeye ait `README.md` dosyasındaki adımları takip edebilirsin.

Repoyu bilgisayarına indirmek için:

```bash
git clone https://github.com/KULLANICI_ADIN/social-media-projects.git
cd social-media-projects
```

Arduino ve ESP32 projelerinde genellikle şu araçları kullanıyorum:

- Arduino IDE
- Visual Studio Code
- PlatformIO
- ESP32 kartları
- Arduino kartları
- OLED ekranlar
- Servo ve DC motorlar
- Çeşitli sensörler
- Hoparlör ve SD kart modülleri
- 3D yazıcı

Her proje için gerekli kartlar, kütüphaneler ve parçalar ilgili proje klasöründe ayrıca belirtilecek.

## Katkıda Bulunmak İstersen 🌱

Bu projeler öğrenmek, denemek ve birlikte geliştirmek için açık.

Katkıda bulunmak için:

1. Repoyu forkla.
2. Yeni bir branch oluştur.
3. Değişikliklerini ekle.
4. Pull Request gönder.

```bash
git checkout -b yeni-fikir
git add .
git commit -m "Yeni özellik eklendi"
git push origin yeni-fikir
```

Pull Request gönderirken yaptığın değişiklikleri kısaca açıklamayı unutma.
