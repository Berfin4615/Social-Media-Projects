## Nasıl Kullanılır? 🚀

İlgilendiğin proje klasörünü açıp o projeye ait `README.md` dosyasındaki adımları takip edebilirsin.

Repoyu bilgisayarına indirmek için:

```bash
git clone https://github.com/KULLANICI_ADIN/social-media-projects.git
cd social-media-projects
```

Arduino veya ESP32 projelerinde genellikle şu araçları kullanıyorum:

- Arduino IDE
- Visual Studio Code
- PlatformIO
- ESP32
- Arduino
- OLED ekranlar
- Servo ve DC motorlar
- Çeşitli sensörler
- 3D yazıcı

Kullanılan kartlar ve kütüphaneler her projenin kendi klasöründe ayrıca belirtilecek.

## Katkıda Bulunmak İstersen 🌱

Bu projeler öğrenmek, üretmek ve birlikte geliştirmek için açık.

Katkıda bulunmak için:

1. Repoyu forkla.
2. Yeni bir branch oluştur.
3. Değişikliklerini ekle.
4. Pull Request gönder.

```bash
git checkout -b yeni-fikir
git commit -m "Yeni özellik eklendi"
git push origin yeni-fikir
```

## Küçük Bir Not ⚠️

Elektronik projelerde bağlantıları yapmadan önce kullandığın parçaların voltaj ve akım değerlerini kontrol et.

Motor, pil, batarya veya harici güç kaynağı kullanılan projelerde yanlış bağlantılar donanıma zarar verebilir. Projeleri kendi ekipmanına göre dikkatli şekilde uyarlamalısın.
